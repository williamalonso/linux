# Linux Mint — Configurações Pessoais

Repositório com documentação das configurações e customizações do meu setup Linux Mint 22.3 (Zena).

## Sobre

Registro detalhado de tudo que foi configurado manualmente no sistema — coisas que não vêm por padrão e que seriam difíceis de lembrar ou refazer do zero.

## O que está documentado

| Tópico | Descrição |
|---|---|
| **Hibernação** | Swapfile, GRUB, initramfs, polkit — setup completo |
| **Bateria** | Controle de carga via `conservation_mode` (Lenovo IdeaPad) |
| **Dual Boot** | Notas sobre convivência com Windows 11 |
| **NVM** | Node Version Manager |
| **Nemo Actions** | Ações de contexto personalizadas (botão direito) |

## Sistema

- **OS:** Linux Mint 22.3 (Zena) — base Ubuntu Noble
- **Kernel:** 7.0.0-30-generic
- **Hardware:** Lenovo IdeaPad, 16 GB RAM, NVMe
- **Setup:** Dual boot com Windows 11

## Por que este repo existe

Toda vez que preciso reinstalar, trocar de máquina ou simplesmente lembrar como fiz algo, está tudo aqui. Também serve como referência se alguém com setup parecido (Mint + Lenovo IdeaPad) quiser replicar.
